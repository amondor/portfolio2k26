# Polices Clash Grotesk

Placez ici les fichiers `.woff2` de Clash Grotesk :

- `ClashGrotesk-Regular.woff2` (weight 400)
- `ClashGrotesk-Medium.woff2` (weight 500)
- `ClashGrotesk-Semibold.woff2` (weight 600)

Si vous n’avez qu’une variable font, adaptez les chemins dans `app/layout.tsx` (par ex. un seul fichier `ClashGrotesk-Variable.woff2` avec `weight: "200 700"`).
